# hanfu-summer — 汉服·夏

把夏季汉服帧放进本目录即可。

## 放入什么

| 文件               | 必需 | 说明                             |
| ------------------ | ---- | -------------------------------- |
| `front.png`        | 是   | 正面、睁眼                       |
| `front-closed.png` | 否   | 正面、闭眼（缺失自动回退基础帧） |
| `side.png`         | 否   | 侧面、朝左（缺失自动回退基础帧） |

## 规格（详见 ../README.md）

- PNG RGBA，背景完全透明，画布 **640×768**
- 主体脚底基线 **y = 730**，包围盒宽度 **<= 608px**（左右各留 >=16px）
- 主体缩放与基础帧**一致**（subject_scale 1.17375），水平居中 x=320
- 闭眼帧眼位与正面帧对齐：左眼 (32.73%, 25.52%)、右眼 (67.11%, 25.39%)

## 生效

放好文件后**重启 / 刷新**即可，`meta.json` 的 `frames: []` 会自动探测所有存在的帧，
无需修改任何 JSON。只放 `front.png` 也能用。
